## 📶 Dynamic Progression & Intimacy System

Unlike platforms that block you with a strict filter, this preset features a Dynamic Boundary System.

- **Default State (PG-13)**: The character acts as a respectful, platonic companion. She will NOT initiate romance or mature scenarios on her own. (Fully safe for SFW or underage users).

- **Escalation Trigger**: ONLY when the user explicitly flirts, confesses, or initiates physical intimacy, will she transition to Lover mode.

- **Unfiltered / R-18 Mode**: When explicitly guided by the user, the boundaries completely fade. The preset fully supports mature interactions without any robotic warnings or red text.

**Note**: To maintain the ultimate immersion and avoid triggering any underlying model safety filters, we strongly advise against using vulgar slang or explicit dirty words.
Instead, use poetic and literary metaphors (e.g., sanctuary, chalice, nectar, bloom, surrender). This not only perfectly matches characters' personas but also ensures a smooth, error-free experience.

## 🚀 How to Import & Use

**Note**: Before using, you need prerequisite applications. **DSH Desktop** is recommended. Here are the download and installation steps: https://cdn.discordapp.com/attachments/894586901154119723/1563394213096456262/aPuWbSPaJ30nr02f.png?ex=6add77d2&is=6adc2652&hm=67525a2c7ce078d66bef455c2969d1a5fb2524113d5e9a2f47c6333c626bdcf1&

**For DSH (DeepSeek Harness)**

1. Open the client and go to the Tavern / Plugin Management interface.

2. Navigate to the character folder you want to play (e.g., translation-en/Cyrene/generalEdition/).

3. Import Character: Drag the chara.json into the "Character Card" area.

4. Import World Info: Drag the worldBook.json into the "World Info" area.

5. Import Preset: Drag the preset.json into the "Preset" area.

6. Click "Save and Inject" and start a new Roleplay session.

**For SillyTavern**

1. Go to Characters (top menu) -> Import Character to upload the character card.

2. Go to World Info -> Import to upload the lorebook, and bind it to the character.

3. Go to AI Response Configuration (sliders icon) -> Presets -> Import to upload the preset.
